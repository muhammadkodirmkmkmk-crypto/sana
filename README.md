# Sana Bogatir — savdo va ombor tizimi

Сервер для системы продаж и склада макаронной фабрики Sana Bogatir.
FastAPI + PostgreSQL + Telegram. Интерфейс — один файл `static/index.html`
(телефон и компьютер, узбекский и русский).

## Роли

| Роль | PIN по умолчанию | Что делает |
|---|---|---|
| `store` — Omborchi | 3333 | приход муки и сдача готовой продукции на склад |
| `seller` — Xayrullo | 1111 | создаёт чек и отправляет на проверку |
| `checker` — Obid | 2222 | проверяет, правит, подтверждает чек, отмечает оплату и долги |
| `director` | 9999 | все отчёты, себестоимость, расходы, отмена чеков |

Товар списывается со склада **только после подтверждения** проверяющим.
Отправленный чек резервирует товар, поэтому его нельзя продать дважды.

## Запуск на Railway

1. Создать сервис из этого репозитория в том же проекте, где стоит Postgres.
2. Подключить базу: переменная `DATABASE_URL` (Railway подставляет сам,
   если сделать Reference на Postgres).
3. Добавить переменные:

```
DB_SCHEMA=sana              # своя схема, чужие таблицы не трогаем
TG_TOKEN=...                # токен бота от @BotFather
TG_CHECKER=...              # chat_id Обида — напоминания о долгах
TG_DIRECTOR=...             # chat_id директора — вечерний отчёт
REPORT_HOUR=19              # час вечернего отчёта
TZ_OFFSET=5                 # Узбекистан UTC+5
SECRET=<любая длинная строка>
PIN_SELLER=... PIN_CHECKER=... PIN_STORE=... PIN_DIRECTOR=...
NAME_SELLER=Xayrullo NAME_CHECKER=Obid NAME_STORE=Omborchi
```

4. Start command берётся из `Procfile`:
   `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. Открыть домен сервиса — появится экран входа с PIN.

Чтобы узнать `chat_id`, напишите боту `/start` — он ответит номером.
Команда `/hisobot` присылает текущий отчёт в любой момент.

## Что делает сервер

- `POST /api/login` — вход по роли и PIN, отдаёт токен на 30 дней
- `GET  /api/state` — всё состояние: товары, склад, чеки, клиенты, долги, настройки
- `POST /api/do` — одно действие; сервер сам считает остатки, себестоимость и долги
- `GET  /api/report` — текст вечернего отчёта (только директор)
- `GET  /health` — проверка

Вся арифметика на сервере: клиент присылает только намерение
(«отправить чек», «подтвердить», «погасить долг»), пересчитывать остатки
или суммы на телефоне нельзя.

Фоном работают: проверка долгов раз в час, вечерний отчёт, приём команд бота.

## Локально

```bash
pip install -r requirements.txt
uvicorn main:app --reload      # без DATABASE_URL поднимется SQLite
```
